A day on set

촬영 하루의 흐름

씬이 바뀔 때마다 아래 순서가 반복됩니다. 시간이 가장 많이 드는 곳은 촬영이 아니라 세팅과 조명이라는 점을 기억하세요.

  1. 집합 · 안전 브리핑

    콜시트를 기준으로 오늘의 목표 컷, 우선순위, 위험 요소(전선·높은 곳·차량)를 3분 안에 공유합니다.

  2. 워크스루 · 블로킹

    배우(출연자)가 실제 동선으로 한 번 움직여 보고, 연출·촬영이 카메라 위치와 앵글을 정합니다. 카메라를 세우기 전에 먼저 본다가 원칙입니다.

  3. 라이팅 · 카메라 세팅

    조명과 카메라를 세팅하는 동안 배우는 쉬고, 스탠드인이 대신 서서 노출과 초점을 확인합니다. 설정 값은 씬 단위로 통일합니다.

  4. 리허설 · 테스트 촬영

    실제 속도로 연기와 카메라 무빙을 맞춰 보며 포커스 마크, 마이크 위치, 그림자를 점검합니다.

  5. 테이크 촬영

    마스터 → 미디엄 → 클로즈업 순서가 일반적입니다. 같은 조명·세팅의 컷을 연달아 찍어 세팅 이동을 줄입니다.

  6. OK 판단 · 기록

    연기 / 기술(초점·노출) / 소리 / 연결 — 네 가지가 모두 통과해야 OK입니다. 결과는 촬영 일지에 기록합니다.

  7. 백업 · 마무리

    그날 촬영한 데이터는 현장에서 복사본이 2개 이상 생기기 전에는 카드를 지우지 않습니다.

Roles

촬영 현장에서 팀별로 할 일

Production team

시간 관리

  • 콜시트 대비 진행 상황을 계속 체크하고 늦어지면 컷 우선순위 조정을 제안
  • 식사·휴식 시간 확보 — 지친 현장은 사고가 납니다

현장 관리

  • 출입 통제, 주민·행인 응대, 주차, 쓰레기·원상복구
  • 전원/발전기, 날씨 대비(우산·방수 커버)

사람 챙기기

  • 배우·스태프 대기 공간, 음료, 개인 짐 보관
  • 컨디션 확인과 안전사고 대응

기록 · 정산

  • 당일 결제 영수증, 출연료/일당 확인
  • 촬영 일지 작성(진행한 컷, 못 찍은 컷, 문제점)

Directing team

디렉팅

  • 테이크마다 한 가지 포인트만 짚어 주기
  • 감정 설명 대신 행동 지시(“시선을 천천히 내려”)

OK 판단

  • 연기, 초점·노출, 소리, 앞뒤 컷과의 연결을 한 번에 체크
  • “안전 테이크(보험)” 한 번 더 — 시간을 아끼려다 재촬영이 더 비쌉니다

컨티뉴이티

  • 의상 · 소품 위치 · 시선 · 손 위치 · 음료 레벨 · 머리카락
  • 연속성 사진 · 영상 메모, 슬레이트 번호 정확히 기록

우선순위 결정

  • 시간이 모자랄 때 어떤 컷을 줄일지 즉시 결정
  • 꼭 필요한 컷을 먼저, 있으면 좋은 컷을 나중에

더 자세한 연출 기법은 연출 노하우 페이지에서 볼 수 있습니다.

Camera team

카메라 세팅

  • 프레임레이트 · 셔터 · 화이트밸런스 · 로그/LUT 확인
  • 설정을 바꾼 이유가 없으면 씬 안에서 고정

노출 · 포커스

  • 제브라/히스토그램/웨이브폼으로 노출 확인
  • 포커스 확대 확인, 포커스 마크 · 후핀(백포커스) 점검

촬영 노하우 보기 →

무빙 · 구도

  • 리허설과 같은 속도로 반복 가능한 무빙
  • 헤드룸 · 룩룸 · 수평 · 프레임 안 불필요한 물체 확인

미디어 관리

  • 카드 교체 시점 정하기(카드가 거의 찰 때까지 쓰지 않기)
  • 촬영한 카드 즉시 백업, 폴더 규칙 지키기

On-set language

현장 콜과 슬레이트

현장이 커질수록 약속된 말이 필요합니다. 순서가 정해져 있으면 누구든 헷갈리지 않습니다.

순서콜누가의미
1“조용히 해주세요 / 스탠바이”연출팀현장 소음을 멈추고 촬영 준비
2“사운드 롤”연출팀 → 녹음녹음 시작
3“카메라 롤”연출팀 → 촬영카메라 REC 시작
4“스피드” (또는 “롤링”)녹음 / 촬영두 장비 모두 정상 기록 중
5“슬레이트” → “씬 3, 컷 2, 테이크 1” + 딱슬레이트 담당씬·컷·테이크 기록, 영상·소리 싱크 포인트 생성
6“액션”감독연기 시작
7“컷”감독촬영 종료(카메라는 컷 후 2~3초 더 돌리기도)
Tip

뮤직비디오·유튜브 촬영처럼 소수 인원이면 콜을 줄이되, “롤링 → 슬레이트 → 액션” 세 가지만은 유지하세요. 편집할 때 컷의 시작과 소리 싱크를 찾기가 훨씬 쉽습니다.

슬레이트에 적는 것

필수
  • 프로젝트명
  • 씬 / 컷 / 테이크
  • 날짜
기술
  • 카메라 번호 (A/B)
  • 프레임레이트
  • 롤 / 카드 번호
메모
  • 감독 / 촬영감독
  • 특이사항(슬로, 인서트 등)
  • 음악 재생 중이면 곡명·BPM

Shoot for the edit

포스트 프로덕션을 위해 프로덕션 때 고려할 것

촬영 중에 5초만 더 투자하면 편집에서 5시간을 아낄 수 있습니다. 아래는 현장에서 습관으로 만들면 좋은 것들입니다.

촬영 때 이렇게 하면편집·포스트에서 얻는 것
컷 시작 전 3~5초, 컷 후 3~5초 여유를 둔다 (“핸들”)트랜지션·디졸브·음악 맞춤 편집이 가능해짐
한 컷에서 끝까지 연기를 이어서 찍는다(중간에 끊지 않기)어느 지점에서든 편집할 수 있는 선택지가 늘어남
씬마다 룸톤(현장 정적 소리)을 30초 녹음한다대사 사이 빈 소리를 자연스럽게 채우고, 컷마다 소리 이질감을 줄임
마스터 → 미디엄 → 클로즈업 → 인서트·컷어웨이 순으로 커버리지를 만든다어색한 컷을 가리고 템포를 조절할 수 있는 “탈출구” 확보
배우의 동작·대사 속도를 컷마다 맞춘다컷을 바꿔 붙여도 동작·감정이 이어짐
씬 안에서 노출·화이트밸런스를 통일한다컬러 작업이 쉬워지고 컷 사이 색이 튀지 않음
배경에 초점이 흔들릴 때를 대비해 인서트·와이드를 추가로 찍는다초점이 아쉬운 컷을 대체하거나 잘라낼 수 있음
슬레이트와 음악 큐 / 손뼉 등 싱크 포인트를 남긴다멀티캠·외부 녹음을 정확히 맞출 수 있음
VFX·합성 예정이면 클린 플레이트(사람 없는 배경)를 5~10초 촬영한다지우기·합성 작업이 훨씬 쉬워짐
카메라 위치/렌즈/높이를 사진으로 남긴다다음 날 재촬영·추가 촬영 때 같은 화면을 재현

Do

  • 마지막 컷 후 “룸톤 하겠습니다” 선언하고 모두 정지
  • 매 컷 끝에 카메라 몇 초 더 돌리기
  • 리액션·디테일·풍경 B컷을 쉬는 시간에 확보

Don’t

  • 오토 노출·오토 화이트밸런스로 찍기
  • “편집에서 고치면 되죠”라며 넘어가기
  • OK 컷만 남기고 NG 포함 모든 테이크를 지우기

Data management

데이터 관리

찍은 영상은 한 번 잃으면 복구할 수 없습니다. 현장에서 가장 비싼 실수는 카드를 지운 뒤에 백업이 없다는 걸 알게 되는 것입니다.

3

사본 3개

원본 카드 + 백업 2개(예: 노트북 + 외장 SSD).

2

매체 2종류

같은 종류의 저장장치에만 두지 않기.

1

한 개는 다른 장소

촬영 종료 후 클라우드 업로드 또는 다른 장소 보관.

# 폴더 구조 예시
2026-11-16_프로젝트명/
├── 01_VIDEO/
│   ├── A_CAM/   # 카드별: A001, A002 …
│   └── B_CAM/
├── 02_AUDIO/    # 별도 녹음 파일
├── 03_REF/      # 연속성 사진, 로케 사진
└── 04_NOTES/    # 촬영 일지, 슬레이트 기록
Warning

카드는 백업 후 해시/용량 확인을 마친 다음에만 포맷합니다. 포맷은 카메라 안에서 하고, 컴퓨터에서 삭제하지 않습니다.

Troubleshooting

현장에서 자주 생기는 문제

상황대처
시간이 부족하다우선순위 컷(★★★)만 확보하고, 나머지는 인서트·와이드로 대체할 수 있는지 감독과 즉시 결정
해가 지고 있다 / 빛이 계속 바뀐다찍을 수 있는 컷 중 빛이 가장 중요한 컷부터 먼저. 노출은 계속 바뀌므로 매 컷 다시 확인
소음이 심하다대사 컷은 와일드 라인(소리만 따로 재녹음)을 현장에서 확보, 불가능하면 후시녹음 계획
배우 컨디션이 떨어진다휴식, 쉬운 컷으로 순서 변경, 클로즈업을 먼저 끝내고 마스터를 짧게
장비가 고장났다Plan B 장비로 대체. 룩이 달라지면 컷 구성을 조정하고 기록 남기기
컷이 서로 안 이어진다연속성 사진 확인 → 지금 고칠 수 있으면 재촬영, 아니면 컷어웨이로 가릴 수 있는지 판단
